# Combat Log Toggle for Return of Reckoning

Standalone, movable toggle for the in-game Combat Log, with right-click controls for opacity and position locking.

The addon source lives in `CombatLogToggle/`. Official releases are listed on the [RoR Addons site](https://addons.returnofreckoning.com/addons/combat-log-toggle).

Contributions and issue reports are welcome. Please describe the tested behavior and keep changes focused. Future releases will be published on the RoR Addons listing.

The module version/date fields use the registry placeholders @project-version@ and @project-date@; tagged releases on the RoR listing fill them in. Use the published package for a ready-to-install build.
